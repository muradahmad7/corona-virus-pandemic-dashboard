# Coronavirus Pandemic Dashboard

## Project Overview

This project is an interactive Coronavirus Pandemic Dashboard developed using Python and Dash.

The dashboard provides an interactive way to explore COVID-19-related data through charts, statistics, and dropdown-based filtering.

## Technologies Used

- Python
- Dash
- Pandas
- NumPy
- Plotly
- Bootstrap CSS
